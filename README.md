# TaskManagement

**TaskManagement** adalah project UI berbasis HTML yang dirancang untuk menampilkan antarmuka manajemen tugas (task management) yang modern, responsif, dan mudah digunakan. Project ini memanfaatkan **Google Stitch** sebagai pendekatan desain untuk menghasilkan tampilan yang rapi, konsisten, dan menarik secara visual.

## ✨ Fitur Utama

* Tampilan dashboard manajemen tugas yang clean dan intuitif
* Desain responsif (desktop & mobile friendly)
* Komponen UI terstruktur (task list, form input, status indikator)
* Penggunaan styling modern dengan pendekatan Google Stitch
* Mudah dikembangkan dan diintegrasikan ke backend apa pun

## 🛠️ Teknologi yang Digunakan

* HTML5
* CSS3
* Google Stitch (UI design approach)

## 📁 Struktur Project

* `index.html` → Halaman utama
* `assets/` → Berisi file CSS, gambar, dan resource lainnya
* `components/` → Komponen UI terpisah (opsional)

## 🚀 Tujuan Project

Project ini dibuat sebagai:

* Latihan pengembangan UI berbasis HTML
* Referensi desain task management sederhana
* Template awal untuk pengembangan aplikasi manajemen tugas

## 📌 Catatan

Project ini hanya berfokus pada sisi **frontend (UI)** dan belum terhubung dengan backend atau database.
